Point d'entrée par `PYTHONPATH=src` ; installation editable non vérifiée.

Fonctionnalités : menu et CLI, inventaire borné, Git passif, profils JS/TS/Next/Python/générique, indices de tests et manifestes, exclusions Git/fixes, fichiers `.env` signalés sans lecture, verdict inconclusif, sorties JSON/Markdown/prompt hors cible. Pas de test sur données personnelles. Aucun test de réseau ni benchmark de performance/tokens.
