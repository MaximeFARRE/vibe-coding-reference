# État du prototype

Dernier lot : 3, START guidé opérationnel et RESCUE avec réserves ci-dessous. Branche locale `feat/initial-publication` ; les notes de recherche et les lots 2–3 ne sont pas poussés. Python 3.12.9 sur macOS ; `pytest` absent, tests `unittest` sans dépendance. Installation editable et Windows non vérifiés.

Fonctionnalités prouvées : START pose un questionnaire local, réutilise les réponses fournies et génère brief, critères, options conditionnelles, prompt et réponses JSON. Six profils sont couverts sur fixtures ; les contradictions reconnues et champs manquants sont explicités. RESCUE produit des rapports avec preuves, options, limites et décisions utilisateur enregistrées hors cible ; verdict inconclusif, aucune commande de la cible exécutée.

Vérification exécutée : `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m unittest discover -s tests -v` : 25 tests réussis. Démonstration sur dossier temporaire : `python3 -m vcr start --interactive --out ...` avec scénario fictif de gestion ; cinq fichiers générés et résultat observable retrouvé dans les critères. La reprise complète/partielle, les champs manquants, dossiers existants et six types de stack sont testés. Une démonstration RESCUE et feedback avait également réussi au lot 2. Pas de données personnelles ni benchmark de performance/tokens.

Limites : choix de stack déterministes et indicatifs, à confirmer ; pas d'étude comparative ni de validation par personne extérieure. Les réponses sont stockées en clair sans détection de secrets. La reprise ne redemande pas les valeurs déjà renseignées, y compris inconnues ; recommencer pour les changer. Pas de déploiement, compte cloud ni modification de projet par START. Pour RESCUE, validation partielle des schémas, preuves d'absence limitées à l'inventaire, détection `.env` sans lecture du contenu, monorepos partiels et comportement concurrent hostile non garanti. Pas de rapport HTML ni tri automatique.
