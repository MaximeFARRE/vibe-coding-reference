# Journal des changements

Les versions publiées décrivent les changements visibles et leurs limites. Le projet est au stade de prototype ; ses interfaces peuvent évoluer.

## À publier — 0.1.0 préversion

- START : cadrage interactif, critères et pistes de stack à valider.
- RESCUE : inspection passive et rapports avec preuves et limites.
- IMPROVE : propositions supervisées depuis des rapports ou notes sélectionnés.
- TOKENS : diagnostic descriptif et import volontaire de formats documentés.
- SOURCES : catalogue local consultable par thème.

Les journaux natifs de session Codex et Claude Code ne sont pas pris en charge ; Windows et l'installation editable ne sont pas vérifiés. Consulter [l'état du prototype](docs/IMPLEMENTATION_STATUS.md) pour les autres limites.
