# Changelog

Published versions describe user-visible changes and their limitations. The project is a prototype; its interfaces may change.

## 0.1.0-rc.1 — preview

- START: interactive scoping, criteria and stack options for review.
- RESCUE: passive inspection and reports with evidence and limitations.
- IMPROVE: supervised proposals from selected reports or notes.
- TOKENS: descriptive diagnosis and voluntary import of documented formats.
- SOURCES: local catalog browsable by topic.

Native Codex and Claude Code session logs are not supported; Windows and editable installation have not been verified. See the [prototype status](docs/IMPLEMENTATION_STATUS.md) for other limitations.
